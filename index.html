Set up Supabase — step by step
  1. Open Supabase Dashboard, create a new project called SportyScope, choose the Free plan if offered, save its database password privately, and wait until the project is ready.
  2. Download the setup SQL. Open the file, copy all its text, then in Supabase choose SQL Editor → New query, paste it and click Run. It creates both the football knowledge tables and private ticket history.
  3. Copy the project URL from the Connect dialog. In Settings → API Keys, copy a server secret key (sb_secret_…). Keep the secret out of this page and chat.
  4. Open your SportyScope project in Vercel → Settings → Environment Variables. Add SUPABASE_URL = the project URL and SUPABASE_SECRET_KEY = that secret key. Select Production and save.
  5. In Vercel → Deployments, redeploy the latest production deployment. Reload SportyScope and click Sync saved tickets. This panel must say Cloud connected. Existing local tickets are uploaded automatically, and later changes sync while the page is open.
  6. Copy your private recovery key and save it in your password manager. On another device, use “Restore history” below with that key. It is separate from Supabase credentials; anyone with this recovery key can access this history.

Raw feed pages and unplaced matches are not permanent ticket records. Generated selections, loaded codes, tracked slips and provider-verified results are saved. Research records persist when requested. A browser must be open for result refresh; this does not create an unattended scheduled worker.
